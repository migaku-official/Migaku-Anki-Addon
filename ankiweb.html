Before you install

You need an active Migaku subscription and the Migaku Browser Extension installed and open.

Create rich flashcards for Anki from Netflix, YouTube, and other websites.

1. Install the add-on

Install Anki Desktop, then add Migaku using this code:

Add-on code: 1846879528

  1. In Anki, open Tools → Add-ons.
  2. Select Get Add-ons…, enter the code above, and confirm.
  3. Restart Anki and complete the Migaku onboarding guide.

2. Connect card creation

Choose Anki as the destination for cards created by the Migaku Browser Extension.

  1. Open the Migaku Extension

    Open Migaku from your browser toolbar.

  2. Open Card Creator settings

    In the Dictionary tab, select Card Creator settings.

  3. Select Anki

    Scroll to “Send card to” and choose Anki.

Done. New cards created with the Browser Extension will now be sent to Anki.

Optional configuration

Customize where cards are saved

Choose the destination deck, note type, and field mappings in the Anki Add-on settings. You can skip this during initial setup.

Turn Word Coloring on or off

Choose which fields use Word Coloring on the front and back of your cards.

  1. In Anki, open Tools → Manage Note Types.

  2. Select the Migaku note type for your language, then select Migaku Options.

  3. Choose Front or Back. Find the coloring option, then set each field to Enabled or Disabled.

What else can the add-on do?

  • Language information in context: See readings, pronunciation, tone, pitch, gender, and parts of speech.
  • Edit while reviewing: Update card fields directly during reviews.
  • Shape your reviews: Adjust grading, ease, card types, and more.
  • Manage your schedule: Balance reviews, plan vacations, retire cards, or promote them.
  • Control your media: Convert audio to MP3, normalize volume, and export condensed audio.
  • Use global hotkeys: Trigger Browser Extension actions like lookups with keyboard shortcuts.
