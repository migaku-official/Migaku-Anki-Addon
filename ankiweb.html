⚠️ NOTE: This add-on requires an active Migaku subscription.

You will also need the Migaku Browser Extension installed and open for card creation.

⬇️ Installing the Anki Add-on

Download and install the Anki Desktop app, if you haven't already.

Then:

  1. In Anki, open Tools → Add-ons.
  2. Select Get Add-ons….
  3. Enter add-on code 1846879528 and confirm.
  4. Restart Anki and follow the onboarding guide to choose your languages and connect the Migaku Browser Extension.

🎴 Creating Cards with Migaku

Using the Migaku Browser Extension, you can create cards from websites like Netflix, YouTube, and more. To send cards to Anki, follow these steps:
  1. Open the Migaku Extension window from the browser toolbar:

  2. In the Dictionary tab, open up Card Creator settings:

  3. Scroll to "Send card to" and select "Anki":
